# 新宿娱乐管理（astrbot_plugin_shinjuku_entertainment）

基于 [AstrBot](https://github.com/Soulter/AstrBot) 的群聊娱乐/管理插件，从「新宿」计费插件中独立拆分而来，后续的群趣味与管理功能（如禁言相关）都在这里扩展。

- 插件名：`astrbot_plugin_shinjuku_entertainment`
- 显示名：新宿娱乐管理
- 版本：v1.0.01
- 最低 AstrBot 版本：>= 4.16

## 目录结构

```
astrbot_plugin_shinjuku_entertainment/
├── main.py            # 插件入口：事件监听、禁言调用
├── metadata.yaml      # 插件元数据
├── _conf_schema.json  # 设置表单（AstrBot Web 控制台自动生成配置页）
└── README.md
```

## 功能特性

- 关键词禁言彩蛋：群内任何人只发送「精致睡眠」即被禁言 8 小时（同时艾特机器人也生效）
- 仅 OneBot V11（aiocqhttp）群聊生效，私聊不触发
- 时长与总开关可在设置表单中调整
- 静默占位指令：`/b50`、`/help` 已被注册，发送后无任何回复（消息被拦截，不继续流转）

## 配置项

设置表单由 `_conf_schema.json` 生成，在 AstrBot Web 控制台的插件配置页中修改。

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `enabled` | bool | true | 是否启用「精致睡眠」禁言彩蛋 |
| `sleep_ban_seconds` | int | 28800 | 禁言时长（秒），默认 8 小时 |

## 关键词触发

| 关键词 | 说明 |
|---|---|
| `精致睡眠` | 仅当消息内容只有「精致睡眠」时触发禁言（默认 8 小时），可同时艾特机器人；仅 aiocqhttp（OneBot V11）群聊生效，机器人需有群管理权限 |

## 注意事项

- 机器人必须在该群有管理员权限，否则禁言会失败；
- QQ 不允许禁言群主和管理员，这类人发送后会收到失败提示；
- 机器人自己的消息不会触发（已做自触发保护）。
- 只有消息内容仅为「精致睡眠」（可同时艾特机器人）时才触发；夹带其他文字、表情、图片等内容不会触发。
